Known issues

  • The game may stutter for a few seconds when loading a level for the first time, due to shader compilation.
  • On some Linux setups, switching to another window while playing can crash the browser's graphics process, which stops the game. Reload to keep playing; progress since your last save is lost.

Saves and settings are kept in this browser. Export them to a file often. Clearing this site's data deletes them.
